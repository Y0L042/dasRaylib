# Changelog

## Unreleased

### Added

- Reference overloads for 131 functions that take a pointer to one value. For example, `UpdateCamera(cam, mode)`, `ImageResize(img, w, h)`, `GuiSliderBar(..., value, ...)` and `Vector3OrthoNormalize(a, b)` now take the variable directly, without `unsafe(addr(...))`. The pointer overloads are still available.
- `raylib_boost`: reference forms of `UpdateCamera(camera, CameraMode)`, `GuiTextInputBox` and `GuiListViewEx`.
- `docs/cheatsheet.html` marks reference parameters with `var`, and labels each overload as the reference form or the pointer form.

### Fixed

- Calls to `Quaternion*` functions that return a quaternion, such as `QuaternionFromAxisAngle`, crashed. They are now bound as `float4` returns.

## 1.0.0 - 2026-11-15

First formal release of the bindings, based on raylib 6.2. Needs daslang SDK 0.6.4 or later.

Windows with MSVC only. Linux and macOS are untested.

### Added

- `dasRaylib`: bindings generated by dasClangBind for `raylib.h`, `raymath.h`, `rcamera.h`, `rlgl.h` and `raygui.h`, using daslang math types.
- `raylib_boost`: color constants, enum overloads, and safe text buffer overloads for raygui.
- `docs/cheatsheet.html`: generated API reference.
- `tests/`: headless test suites.
- `manage.bat`: the `manage.sh` commands for cmd.exe.
- `.das_package`: `resolve()`, so `daspkg install ...@1.0.0` installs a tagged release.

### Removed

- The older hand-written `rl_das` module, its premake build and its test host.

### Breaking

- The `rl_das` helpers are gone, including `make_color`, `make_vector3`, `rectangle_overlaps` and `log_info`. Use daslang types directly, such as `float4` for colors and `float3` for vectors.
- `manage.sh` commands are renamed: `gen-dasraylib` is now `gen`, `build-dasraylib` is `build` and `run-dasraylib` is `run`. `package` now writes to `dist/raylib/`.
