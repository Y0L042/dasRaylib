# Changelog

## Unreleased

First formal release of the bindings, based on raylib 6.2.

### Added

- `dasRaylib`: bindings generated by dasClangBind for `raylib.h`, `raymath.h`, `rcamera.h`, `rlgl.h` and `raygui.h`, using daslang math types.
- `raylib_boost`: color constants, enum overloads, and safe text buffer overloads for raygui.
- `docs/cheatsheet.html`: generated API reference.
- `tests/`: headless test suites.

### Removed

- The older hand-written `rl_das` module, its premake build and its test host.

### Breaking

- The `rl_das` helpers are gone, including `make_color`, `make_vector3`, `rectangle_overlaps` and `log_info`. Use daslang types directly, such as `float4` for colors and `float3` for vectors.
- `manage.sh` commands are renamed: `gen-dasraylib` is now `gen`, `build-dasraylib` is `build` and `run-dasraylib` is `run`. `package` now writes to `dist/raylib/`.
